Fonts bundled with Ray Client
=============================
Inter, Outfit, JetBrains Mono, Tektur and Work Sans are distributed under the SIL Open Font License,
Version 1.1. Each font's license text is in this folder (*-OFL.txt).

Outfit, JetBrains Mono, Tektur and Work Sans are included unmodified. Inter (Medium and SemiBold) was subset to
Latin, Greek and Cyrillic and converted from OpenType (CFF) to TrueType outlines so Minecraft can load it; the
design itself is unchanged. Inter has no Reserved Font Name.
